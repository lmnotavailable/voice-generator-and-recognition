# Русская озвучка текста с Qwen3-TTS

Небольшой локальный скрипт для озвучивания UTF-8 `.txt` в WAV. Он использует Qwen3-TTS VoiceDesign 1.7B и задаёт модели разговорную, живую манеру чтения. Веса модели в репозиторий не входят: их нужно скачать отдельно.

## Как это устроено

Скрипт читает текстовый файл и передаёт его модели вместе с языком `Russian` и текстовым описанием желаемой подачи. Модель генерирует аудио, а `soundfile` сохраняет результат в WAV.

VoiceDesign создаёт голос и манеру по текстовой инструкции. Это не система специальных тегов для точного управления звуками: модель не гарантирует запинки, мыканье, вздохи или чмоканье в строго заданных местах. Заполнители вроде «э-э» можно написать в самом тексте, но их произношение зависит от генерации. Для звуков рта обычно нужен отдельный монтаж аудио.

## Требования

- macOS с Python 3.11; проверенная установка делалась на Mac с Apple Silicon и Python 3.11.
- Несколько гигабайт свободного места для весов модели.
- Доступ в интернет при первоначальной установке пакета и загрузке модели.
- Для запуска используется CPU. На указанном Mac PyTorch не обнаружил MPS, поэтому длинные тексты синтезируются медленно.

## Установка

Сначала скачайте проект и перейдите в его папку:

```bash
git clone https://github.com/lmnotavailable/voice-generator-and-recognition.git
cd voice-generator-and-recognition
```

Создайте виртуальное окружение и установите библиотеку:

```bash
python3.11 -m venv ~/qwen3-tts-env
source ~/qwen3-tts-env/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Установите Hugging Face CLI и скачайте VoiceDesign 1.7B:

```bash
python -m pip install -U huggingface_hub
mkdir -p ~/qwen-models
hf download Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign --local-dir ~/qwen-models/Qwen3-TTS-12Hz-1.7B-VoiceDesign
```

Код модели и её веса опубликованы под Apache 2.0. Перед распространением весов прочитайте лицензию и уведомления в карточке модели Qwen.

## Использование

Активируйте окружение и запустите скрипт, указав путь к `.txt`:

```bash
source ~/qwen3-tts-env/bin/activate
python src/ozvuchit.py ~/Downloads/текст.txt
```

Или запустите без аргумента — скрипт запросит путь интерактивно:

```bash
python src/ozvuchit.py
```

В Terminal можно перетащить `.txt` из Finder и нажать Enter. WAV по умолчанию появится рядом с текстом, с суффиксом `_озвучка`. Например, `текст.txt` станет `текст_озвучка.wav`.

Можно задать отдельный путь для результата:

```bash
python src/ozvuchit.py ~/Downloads/текст.txt --output ~/Downloads/результат.wav
```

Если модель хранится в другом месте, укажите путь явно:

```bash
python src/ozvuchit.py ~/Downloads/текст.txt --model ~/путь/к/Qwen3-TTS-12Hz-1.7B-VoiceDesign
```

## Настройка манеры чтения

По умолчанию задана быстрая, разговорная подача. Своё описание можно передать параметром `--style`:

```bash
python src/ozvuchit.py ~/Downloads/текст.txt --style "Speak Russian warmly and casually, at a brisk pace, with clear articulation."
```

В инструкции лучше описывать общий стиль и темп. Не считайте квадратные скобки вроде `[чмоканье]` специальной командой модели: они могут быть прочитаны как обычный текст.

## Работа с ветками

- `main` — исходная версия проекта.
- `friend-upload` — предлагаемое имя отдельной ветки для работы друга. Друг может переключиться на неё, внести изменения и отправить их в этот же репозиторий.

После клонирования репозитория друг создаёт свою ветку так:

```bash
git switch -c friend-upload
# После добавления своих файлов и коммита:
git push -u origin friend-upload
```

## Что не хранится в Git

В репозиторий не следует добавлять веса модели (`*.safetensors`), кэш загрузок, виртуальное окружение, пользовательские аудиозаписи и готовые WAV. Веса скачиваются отдельно по инструкции выше.
